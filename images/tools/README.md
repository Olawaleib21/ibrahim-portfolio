# Local tool icons

Downloaded from [theSVG](https://thesvg.org/) on 13 November 2026. The website references these SVG files with relative paths; it does not load icons from theSVG, a CDN, or an icon package.

`sources.json` records each download URL, brand URL, and the licence reported by the source registry. Brand names and logos belong to their respective owners and identify the tools used in this portfolio.

Icons: CorelDRAW, Photoshop, Illustrator, InDesign, CapCut, Figma, HTML5, CSS3, JavaScript, Elementor, WordPress, Git, and GitHub. Each SVG was parsed and checked for active scripts and external references before being saved.
